① Vocus 文章網址 → AI 轉 JSON 指令

貼上 Vocus 文章網址，按下按鈕後，系統會自動產生一段「請 AI 閱讀文章並整理成 farmers.json」的指令。 複製後貼到 ChatGPT，即可請 AI 產生可放進農人足跡地圖的 JSON。

AI 轉 JSON 指令

建議流程：貼上 Vocus 網址 → 產生 AI 指令 → 複製到 ChatGPT → 取得 JSON → 貼回下方表單或直接放入 farmers.json。 這種方式不用放 API Key，也不會產生額外費用。

② 手動輸入農人故事資料

建議先從 Vocus 文章或學生訪談稿中整理重點，再填入下方欄位。

小提醒：X/Y 座標是標記在台灣地圖上的百分比位置。之後換成真實 SVG 地圖後，只要微調 X/Y，就能把標記放到正確縣市。

④ 建議使用流程

      

        

          1. 從文章整理資料
          
閱讀 Vocus 或學生訪談稿，先抓出農場、作物、地點、故事重點。

        

        

          2. 產生 JSON

          3. 放進地圖資料庫
          
把資料貼入 farmers.json，農人足跡地圖就能讀取並顯示。
